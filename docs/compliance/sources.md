## Retrieval limitations

- **rbidocs.rbi.org.in PDFs** return a CAPTCHA. The equivalent rbi.org.in HTML renderings were used. Paragraph numbers from automated extraction should be confirmed by a human reader.
- **npci.org.in:** `/PDF/` paths return Access Denied; `/uploads/` works; product and FAQ pages are JavaScript-rendered.
- **meity.gov.in** returns 403. The DPDP Rules text was read from a third-party copy of the Gazette PDF.
- **Automated page summaries were unreliable once.** A summariser misidentified the DPDP Rules PDF as "2023 / GSR 663(E)". That output was discarded, and the PDF text was extracted and read directly. Treat other automated extracts with the same caution.
